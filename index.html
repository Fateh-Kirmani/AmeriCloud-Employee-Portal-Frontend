Non-Billable Time Codes

These nine codes are for time you do not bill to a customer. On such a day, type the LBR code into the Project Code column on the timesheet. On a normal day, type the project code your manager gave you. Do not type a service code. Expenses go on RAMP, not here.

CodeWhat it isWhen to use it
LBR1010Idle / Bench TimeAvailable, unassigned, no active project
LBR1020Paid Time Off (PTO)Vacation and personal PTO
LBR1030HolidayCompany-observed holiday
LBR1040Sick / Safe TimeSick or protected safe time
LBR1050Bereavement / Jury DutyBereavement, jury, witness leave
LBR1060Training and CertificationTime in training or certification
LBR1070Non-Billable Travel TimeTravel hours not chargeable to a customer. Travel we DO bill is SVC2000.
LBR1080Administrative / InternalInternal meetings, admin, timesheets
LBR1090Safety / Stand-DownSafety stand-downs, toolbox talks
